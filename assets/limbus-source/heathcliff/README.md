# Heathcliff source asset archive

Source art and sprite atlases from the user-provided `LCB Sinner-20261029T153416Z-1-001.zip` are preserved here without modifying the original filenames.

The runtime art is a separate set under `assets/images/battle/heathcliff/`; it is renamed and selected for the current Canvas renderer. The `10701_Heathclif_Base_C6Appearance` source files are preserved for future identity work, but are not currently a selectable form in the game.

Voice files from `LCB Sinner-20261029T154101Z-1-001.zip` are preserved in `assets/audio/heathcliff/` and indexed by `js/data/voiceLines.js` and `assets/data/limbus-library/catalog.json`.
